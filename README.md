# Steady Scale

A simple, mobile-first weight loss tracker. It's a single HTML file with no build step and no dependencies.

## Features

- **Today:** see the calories you have left, and log food and exercise.
- **Exercise by distance:** pick walk, run or cycle, enter the km, and it works out the calories from your weight.
- **Weight:** log weigh-ins, see a smoothed trend chart, and track progress to your goal.
- **Setup:** a daily calorie target from the Mifflin-St Jeor formula. It updates as your weight changes and never drops below 1,200 kcal for women or 1,500 kcal for men.

## Run it

Open `index.html` in a browser, or turn on GitHub Pages for this repository.

When the app runs on its own like this, your data is saved in your browser on that device. Saving to your Claude account and the "Estimate kcal" button only work when the app is opened as a Claude artifact.

The calorie figures are estimates, not medical advice.
